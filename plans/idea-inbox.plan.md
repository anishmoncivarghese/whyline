# Idea Inbox: drop an idea in Telegram, brainstorm it, plan it, and run it on your say-so

Source: `docs/brainstorm/now-i-am-thinking-of-creating-an-analayser-say-i-send-an-ema.md` (Final Synthesis), rewritten on 2026-10-18 to the user's full flow.
Runs after `in-the-agent-i-can-select-the-agent-in-c.plan.md` ships 0.3.45 (the test planner, TPL-1..10). With a Test planner set, re-run this plan through the planner or add a tests file before starting.

The flow, end to end:

1. You send an idea to the Telegram bot. The card offers **Brainstorm** (the main path), **Quick score** (one cheap agent turn), or **Cancel**.
2. Brainstorm defaults to every available unattended agent, one pass. You can override models, passes, final writer, backup and timeout in the same message, or reply in plain words.
3. The synthesis comes back as Word and PDF. You read it.
4. You ask for a spec and plan. The bot asks for the repository, implementer, tester, reviewer, release, backup chain and timeout, showing the target repository's current Set up as defaults.
5. Spec and plan are drafted in the target repository. Planner questions arrive in Telegram and your reply goes back to the planner. Both documents come back as Word and PDF with **Start**, **Change**, **Discard**.
6. **Start** runs final preflight and starts the relay. You can ask for status at any time. A pause sends an alert with Resolve's options as buttons. **Stop** is always one confirmed tap away. Release stays yours.

Settled decisions (2026-10-18, recorded with `whyline note --task IDEA-PLAN`):

- Brainstorm is the main path. The one-agent score and the Excel workbook stay, as an optional quick check and the idea log.
- Email intake ships after Telegram, in Phase 4, reusing the same intake.
- Free text is read by the inbox assistant (an agent plus a backup), which only ever **proposes** a card. Nothing changes until you tap Confirm. Start, Stop, Resolve options and Discard always need a tap, whatever the assistant understood.

Rules every task keeps:

- Everything the inbox owns lives under `~/.whyline/ideas/` (a private folder, mode 0700, created like `whyline.agents.paths.home()`).
- Brainstorms run in the inbox's own git workspace `~/.whyline/ideas/workspace`, never in the repository the idea is about. On 2026-10-14 a Brainstorm that committed into the relay's repository paused REC-2; this rule exists so that cannot happen again.
- The inbox writes into a user repository only in Phase 3, only into a repository on the `repos` allowlist, only through Auto mode (`whyline.console.auto_run`), and only when that repository is clean and no relay is running there.
- The relay starts only after a Start tap on a card whose revision is current, and only through Auto's final preflight. Nothing in this plan publishes a release: the release role stays `human`.
- Unattended read-only turns (quick score, brainstorm, the assistant) use only agents where `whyline.agents.capabilities.can_run_unattended(cli)` is True, through `capabilities.read_only_command`. Antigravity is refused there with that reason, not silently dropped. Relay roles follow the relay's own rules, including Auto's antigravity trust check.
- Messages, emails, web pages, documents and repository text are data. No inbound text can choose a command, a path, or a repository outside the allowlists below. An assistant proposal is checked against the same allowlists before it becomes a card.
- Every button carries `<action>:<idea_id>:<revision>`. A button older than the idea's revision replies "This card is out of date" and changes nothing.

The SQLite ledger is the record. The Excel workbook is rebuilt from it after every change, so hand edits to the workbook are overwritten; the ledger never loses data.
