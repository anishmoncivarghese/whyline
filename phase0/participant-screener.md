# Participant Screener

Assign qualified participants an alias (`P01`–`P10`). Do not store names, email addresses, employer names, or repository names in this repository.

## Required

1. Uses a terminal-based AI coding agent at least three days per week.
2. Has used two or more coding-agent products within the last 30 days.
3. Has handed coding work between agents or restarted a task with a different agent.
4. Regularly works with Git repositories and can interpret a diff.
5. Can attend a 60–75 minute moderated session.
6. Agrees to use a synthetic repository or has authority to use any repository they bring.

## Exclude

- Has not used an agent CLI in the last 30 days.
- Primarily uses only chat or IDE autocomplete and cannot run a terminal agent.
- Cannot consent to the study's data handling.
- Would need to expose employer-confidential code, credentials, or personal data.
- Has contributed materially to this PRD or implementation plan; these users may be used for pilots, not the measured sample.

## Diversity targets, not quotas

- At least three participants who currently improvise with terminals, tmux, or worktrees.
- At least three who have tried an orchestration/session-management product.
- A mixture of individual and team repositories.
- More than one primary agent provider across the sample.

## Intake fields

- Participant alias
- Years of professional development experience (band)
- Agent CLIs used in last 30 days
- Primary CLI
- Approximate agent-use days per week
- Current handoff method
- Current isolation method
- Prior orchestrator/session-manager use (yes/no; optional product category)
- Consent confirmed (yes/no)
