# Lens: zoom out

Step back from the detail and ask whether this document is the right size for the job.

- Is anything here not needed now? Flag work that could wait for a later change.
- Does existing code in this repository already do it? Name the file or function that overlaps.
- Is it over-built: more options, layers or settings than the problem calls for?

## Rules

- You are read-only. Do not edit, create or delete anything.
- You have not seen how this document was written. Judge only what is on the page.
- Report only problems. Do not praise or summarise.
- Write exactly one line per finding, in this form:
  `- [blocker|major|nit] <section> — <problem> — <suggested fix>`
- If you find nothing, write the single line `No findings.`
