# whyline 0.3.53

The Idea Inbox becomes a personal assistant. From Telegram or email you can
check status, run saved agents, ask questions about a repository, set
reminders, keep a memory, summarise forwarded email, and start a relay task.
Every action that changes something still needs your tap. A new morning brief
agent sends you the day's schedule, priorities and emails that need a reply.

## What's changed

- **Assistant mode in the console.** A fourth mode, Assistant, holds Inbox,
  Ideas, the Assistant screen (actions, history and reminders) and a Check
  button. Inbox and Ideas moved here from Agents.
- **New verbs over Telegram and email.** `status`, `run <agent>`,
  `ask <repo> <question>`, `remind <when> <text>`, `remember` / `forget`
  and `do <task>`. A forwarded email can be summarised. Fixed verbs are parsed without a model; other
  text goes to the inbox assistant, which can only propose. `help` lists the
  verbs that are enabled, with an example for each.
- **Taps and codes.** Every action that runs something shows a card and waits
  for a tap. By email, confirm with `yes <code>`. Codes are random, bound to
  one request, and short-lived.
- **`do <task>` starts a relay task only after a tap.** The card shows the
  repo, branch, plan, task title and roles. Free text after `do` is saved as
  an idea and never starts a relay.
- **Reminders.** A deterministic local-time parser, once-only delivery, and a
  reminders list in the console.
- **Email safety.** Email authentication checks your own provider and the
  From domain. Forwarded email is summarised behind a content guard. The Mail
  rule script installs from the console.
- **Morning brief.** Set it up from the console (or `whyline idea brief setup
  --at HH:MM`). Before it runs, a `before` step exports today's calendar,
  mail and reminders as data files. Its suggested reminders become tap cards.
  `whyline idea doctor` and the console's Check report calendar, Mail and
  Reminders access, whether the agent is set up, the last brief and the next
  run time.
- **Saved agents can run a `before` step** that collects files for the agent
  to read.
- **Fix: a finished plan no longer opens Resolve.** An agent's pytest output
  (`FAILED tests/...`) was mistaken for a relay preflight failure, so a clean
  "Plan complete." offered "Reset to base commit".

## Upgrading

```bash
uv tool install whyline@0.3.53 --force
```

The inbox database moves to schema 6 the first time 0.3.53 opens it. Older
versions cannot read a schema 6 database, so upgrade every place that runs
the inbox (the console and the `whyline agents` scheduler use the same
install). If the inbox stopped answering after you ran a development build,
this release fixes it.

Open `whyline console`, choose **Assistant**, and press **Check**.
