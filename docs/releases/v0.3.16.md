# whyline 0.3.16

One install command, nothing to forget. Until now the console's Chat and
Relay modes needed the `relay` extra, and a plain `uv tool install whyline`
(or one with only `[console,ui]`) opened a console whose Chat mode failed
with "No module named 'whyline_relay'".

## What's changed

- **whyline-relay, prompt_toolkit and textual are now required
  dependencies.** `uv tool install whyline` gets the relay and the
  full-screen console. The `[relay]`, `[console]` and `[ui]` extras remain
  as empty aliases so existing install commands still work. The relay is
  still never set up in a repository or run unless you ask
  (`whyline init --relay` / `whyline relay init`).
- **No dependence on a `whyline-relay` executable.** Installed as a
  dependency, its executable isn't on PATH, so every hand-off (the entry
  menu's chat and setup, the console's first-time relay setup) now goes
  through `whyline relay <command>`.
- **The entry check tests what actually matters.** Bare `whyline` used to
  decide whether to open the console by looking for `whyline-relay` on
  PATH -- which passed when it was installed as a separate tool, even
  though whyline itself couldn't import it. It now checks importability.
- **A fix-it message instead of a raw import error** if the relay is ever
  missing: "Chat and Relay need whyline-relay ... Run: uv tool install
  --reinstall whyline".
- **`/model Claude` works**: agent names are case-insensitive.
- **/help shows a real example** (`/model claude opus`) instead of bracket
  notation that read as literal text.
- README: single install command, and the no-argument `whyline` section now
  describes the console.

## Upgrading

```bash
uv tool install --reinstall whyline
```

## How it was checked

- Built the wheel and installed it into a clean environment with no
  extras: whyline-relay, textual and prompt_toolkit all importable, the
  console available, and `whyline relay --help` works.
- New tests for importability-based detection, the fix-it message (and that
  other missing modules still raise), case-insensitive `/model`, and the
  help example. Full suite green.
