# whyline 0.3.4

`whyline model`'s interactive prompt now offers Grok too. A follow-up fix, found in a post-release review of 0.3.3, not a new feature.

## Fixed

- **`whyline model` (no subcommand) now prompts for Grok's model**, alongside Codex/Claude/Antigravity. `cmd_model`'s interactive loop hardcoded its own agent tuple instead of deriving it from `runner.AGENTS` the way `run`/`model set` already do, so it silently missed Grok when 0.3.3 added it. `whyline run grok` and `whyline model set grok <model>` were unaffected — only this interactive path was stale.

## How it was checked

- 323 tests (322 before).
- Reviewed by re-checking every `antigravity`-specific site in the codebase for a matching `grok` counterpart; this was the one gap, caught by the existing test that locked in the old, 3-agent prompt count.

## Known issues

Same as 0.3.3.
