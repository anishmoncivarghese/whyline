# whyline 0.3.27

Fixes from starting whyline in a new project folder.

## What happened

`~/TradingPlatform` was a new folder with no git repo of its own. whyline
walked up the folder tree and used the next repo it found, which was the
home directory's own git repo, without saying so. The brainstorm then ran
against `~`; typed `/agents` and `/default codex` were sent to Claude as chat
messages; one of those turns committed a file into the home repo; and git
stalled on an `index.lock`, because `git status` in a home directory that
large times out.

## What's fixed

- **whyline offers to set up the folder you're in.** Starting `whyline` or
  `whyline console` in a folder with no git repo of its own, or whose only
  repo above is your home directory's, now asks: "Set one up here (git init
  + whyline init)? [Y/n]". Yes sets it up and opens the console there. A
  subfolder of a real project (e.g. inside a monorepo) still uses that
  project's repo without asking, and nothing is ever created when there's no
  terminal to ask in.
- **The home-directory repo is guarded.** If the console does end up there,
  it says so at startup, and Chat, Relay and Brainstorm refuse to run with
  a pointer to `/repo`. Command mode still works.
- **Unknown commands are never sent to the agent.** `/agents`, `/default`,
  `/claude` and other `whyline relay chat` commands now get "Unknown command
  … here, /model …" instead of becoming a chat message (which could also
  start a turn in the middle of a brainstorm).
- **Copy really copies.** It uses the system clipboard (`pbcopy`, `wl-copy`,
  `xclip`, `xsel` or `clip`). The terminal escape code it used before
  (OSC 52) is ignored by several terminals, so "Transcript copied" could be
  untrue. When no clipboard command exists it still tries OSC 52, and now
  says it may not have worked.
- **Brainstorm progress is printed once, not twice.**
- **A brainstorm stops when no model finishes its research**, instead of
  running a review and a synthesis over nothing.
- **Skipped models say how to add them:** "… -- add them with: whyline relay
  setup".

## How it was checked

- New tests for the setup offer (yes, no, no repo anywhere, monorepo
  subfolder, no terminal, `whyline console`), the home-repo guard and
  startup warning, unknown commands in both consoles, both copy paths and
  the platform command, single progress lines, the early stop, and the
  setup hint.
- Copy checked against the real macOS clipboard (`pbcopy`, then `pbpaste`).
