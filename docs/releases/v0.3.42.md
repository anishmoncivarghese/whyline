# whyline 0.3.42

Recovery and Resolve: a relay that stops for a known reason can now be
fixed with one click, or with no click at all in Auto.

## What's changed

- **Auto commits the relay's own decision log and resumes.** When the only
  uncommitted file is `.whyline/decisions.md`, Auto commits it and continues
  instead of stopping on the clean-tree check.
- **A missing handoff gets one constrained recovery turn.** The selected
  agent, then the backup chain, may only record the handoff. If it changes
  anything else, moves HEAD, or leaves no new handoff, the result is reported
  to you and nothing resumes.
- **Recovery never edits task code and never skips the clean-tree check.**
  It resumes only after the repository preflight passes. Login, blocked,
  round-cap, and release pauses still stop for you.
- **Resolve in Set up and next to Resume.** A failed Check or Resume
  explains each problem with its evidence and offers fixes, the recommended
  one first: commit the decision log, resume and keep paused work, stash,
  reset after a stray commit, reset a sticky backup switch, raise the
  timeout, or switch to an agent that still has usage. Fixes that can lose
  work ask you to confirm first.
- **Problems Resolve does not know go to the selected agent, read-only.**
  The agent, then the backup chain, explains the problem and recommends one
  of the listed fixes. It cannot change anything; your click applies it.
- **Set up's Resolve select: Review or Auto.** Review waits for your click.
  Auto applies the recommended fix and continues, once per task and round,
  except stash, reset, moving commits aside, and stopping a relay, which
  always wait for you.
- **Commits from another whyline run are not blamed on the agent.** Commits
  that a Brainstorm or plan run makes during a stage are diagnosed as such,
  and Resolve moves them to their own branch instead of folding them into
  the task.
- **Sandbox refusals are explained, and a capped stage can be retried.** The
  pause card shows the refused command, and a stage that hit its visit cap
  offers Retry stage once.

Needs whyline-relay 0.2.36.

## Upgrading

```bash
uv tool upgrade whyline
```
