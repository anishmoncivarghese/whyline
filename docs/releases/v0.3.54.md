# whyline 0.3.54

The morning brief reads Reminders again, and a refused macOS permission now
tells you exactly what to switch on. The console's button bar stays on one row.

## What's changed

- **Reminders fixed.** The brief's Reminders export failed with "Can't make
  missing value into type date" whenever any open reminder had no due date.
  Reminders without a date are now skipped.
- **Exact permission steps.** When macOS refuses Calendar, Mail or Reminders
  access, the message names the app it asked about (Terminal, iTerm, Ghostty,
  your editor), gives numbered steps, and the Assistant screen shows
  **Open System Settings**, which opens the right page (Calendars, or
  Automation for Mail and Reminders). The CLI has the same:
  `whyline idea brief open-settings calendars|automation`.
- **One-row button bar.** In Agents and Assistant the buttons no longer spread
  across a wide window in a six-column grid; they wrap only when the window is
  too narrow. Files is hidden in Agents and Assistant, which work on no
  checkout.
- **Morning brief time box** shows the whole `07:00`.
- **Docs.** `docs/assistant.md` points to the Assistant mode, shows
  `do <repo> <TASK-ID>`, and explains the macOS permission steps.

## Upgrading

```bash
uv tool install whyline@0.3.54 --force
```

Then open `whyline console`, choose **Assistant**, press **Assistant…**, and
press **Grant Calendar access and preview** again.
