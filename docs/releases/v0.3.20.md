# whyline 0.3.20

Brainstorm roadmap item 2: ownership claims and handoffs stop presenting
finished work as current. On this repository, `sync` had been showing 25
ownership claims from finished tasks and an approved handoff 31 commits old
as the active task, which also narrowed which decisions it showed.

## What's changed

- **Claims are leases.** A claim expires after 72 hours unless
  `whyline claim … --ttl HOURS` says otherwise; claiming again renews it.
  Claims made before this release expire 72 hours after they were made.
- **A claim also retires when its task is finished**: when a handoff with a
  finished status (approved, completed, done, merged, cancelled, …) or an
  explicit `handoff close` is recorded for its task after the claim. A
  claim made after that stands.
- **Stale claims stay inspectable but stop counting.** They no longer cause
  overlap warnings. `sync` shows live claims plus one line: "(24 stale claims
  hidden -- expired or task finished; clear with: whyline release --stale)".
  `sync --json` lists them under `ownership.stale`; `status` shows both
  counts.
- **New release forms:** `whyline release TASK` (every actor's claim on the
  task), `whyline release --stale`, `whyline release --all`. The existing
  `whyline release TASK --actor A` is unchanged. Each reports how many
  claims it released.
- **`whyline handoff close [--status completed|cancelled] [--summary …]`**
  closes the active handoff and records a `HandoffClosed` event. The fields
  whyline-relay routes on (`id`, `status`, `to_actor`) are left untouched.
- **Settled handoffs.** A closed handoff, or one with a finished status
  whose commit HEAD has since moved past, appears in `sync` as one line
  ("Last handoff: FC-3 (approved, at eadabbc, 31 commits ago)") instead of
  as active work, and no longer picks the default task or ranks files.
  `sync --json` moves it to `last_handoff`. A finished handoff still at HEAD
  is shown as active, since it's still the latest news.
- `whyline timeline` shows the task and status of handoff events.
- The installed AGENTS.md block now tells agents to close handoffs and
  release claims when a task is finished (run `whyline init` to update it).

## How it was checked

- 31 new tests in `tests/test_staleness.py` covering leases (including
  claims from before leases existed), finished-task retirement, every
  release form, closing, settled detection (closed, finished and behind,
  finished at HEAD, open, unknown commit), and sync/status/timeline output.
- Run against this repository's real state: 24 of 25 claims retired (the
  one left was claimed after its task's approval, so it honestly stays),
  and FC-3 shown as the last handoff.
