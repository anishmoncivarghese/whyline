# whyline 0.3.35

Pick the agent, model and repo from the console itself, set up any folder in
one step, and see only the buttons that mean something in each mode.

## What's changed

- **A context bar** under the mode buttons: **Agent**, **Model**, **Repo**,
  **all repos** and **Save**. Save stays greyed until something changes.
  Agents that aren't available show why (for example "Run /login grok") and
  snap back.
- **Saved default agent and model, per repo and global.** Save sets this
  repo's default; tick **all repos** to make it the default everywhere else
  too. The console starts on it, and `/model` saves it the same way.
- **Typing a repo that isn't set up offers to set it up:** create the folder,
  `git init`, `whyline init` and the relay's agent permission files, after one
  confirmation, then a first commit of only the files setup created. Your
  home folder and folders inside another repo are refused. A setup that stops
  partway is finished by the next try, and nothing it wrote is left
  uncommitted.
- **Command mode is gone.** Run any whyline command from any mode as
  `/<command>`, for example `/status` or `/relay doctor`. `/help` lists them.
  The console opens in Chat; the modes are Chat, Relay and Agents (Agents
  arrives in a later release).
- **Each mode shows only its own buttons.** Attach is in Chat only; Stop, Help
  and Copy come last everywhere.
- **Fix:** a finished relay run no longer asks for `done`/`skip` when an agent
  happened to print the release-task text while working.

Grok's fix, where a cancelled turn is resumed, comes from whyline-relay 0.2.32.

Needs whyline-relay 0.2.32.

## Upgrading

```bash
uv tool upgrade whyline
```
