# whyline 0.3.28

Brainstorms get a per-agent timeout you can set from the console. Requires
whyline-relay 0.2.25.

## What's changed

- **The Brainstorm form has a "Per-agent timeout" dropdown** (15, 30, 45 or
  60 minutes; 15 by default). It bounds every agent turn in the brainstorm:
  the independent research, each review pass and the final write-up. A
  provider that stalls now costs at most that long instead of holding the
  whole console.
- whyline-relay 0.2.25 is now the minimum version, since it is the release
  that accepts the timeout.

## Upgrading

```bash
uv tool upgrade --refresh whyline
```
