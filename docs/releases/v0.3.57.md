# whyline 0.3.57

Job search, part 2: each weekday morning whyline fetches new jobs from the
companies you watch, an agent scores them against your rubric, and you get a
ranked shortlist plus a tracker you manage in the console. If nothing is new,
no agent runs and no subscription usage is spent.

## What's changed

- **New jobs from public job boards.** whyline reads the boards of your
  accepted companies (Greenhouse, Lever, Ashby, Workable, SmartRecruiters and
  Recruitee) through their documented public endpoints, and turns each posting
  into plain text. One board failing never stops the others.
- **Safer job text.** Hidden HTML text, comments and invisible characters are
  removed. Lines that try to address an AI ("ignore previous", "you are",
  "system prompt", …) are kept but marked `[flagged by whyline]`, and the
  agent is told never to follow them.
- **Your filters, applied first.** Location, remote, role keywords and
  deal-breakers from your preferences drop postings before any agent sees
  them. A private `~/.whyline/jobs/jobs.sqlite` remembers what you've already
  seen, so each run only scores new postings.
- **Fetch now.** `whyline jobs fetch [--dry-run]`, or **Fetch now** on the
  Jobs screen, shows new, dropped and failed counts per company. A dry run
  marks nothing as seen.
- **Daily job shortlist template.** `whyline agents new --from job-search`
  (or Agents → New agent → Daily job shortlist) creates a weekday 07:30 agent
  that scores each job 0–25 against your rubric and sends a ranked shortlist
  through its email or Telegram delivery.
- **Job tracker.** Every scored job lands in a tracker. `whyline jobs list`,
  `whyline jobs set <job> <status> [--note TEXT]` and `whyline jobs excel`,
  or the **Jobs** section of the Jobs screen: sort by score, filter by status,
  set status (shortlisted, applied, interview, offer, rejected, archived), add
  notes, open the link, or open `jobs.xlsx`. Your status changes are kept when
  the next run scores the same job again.
- **Setup check.** `whyline jobs doctor`, also on the Jobs screen, checks your
  CV, profile and rubric, companies with a known board, the job-search agent,
  an enabled runner, and the scheduler, with a fix for each problem.
- **Agents.** A saved agent's `before` step now chooses from built-in steps
  (`brief-collect`, `jobs-fetch`). A step that finds nothing ends the run as
  `nothing_new`: no provider starts, nothing is delivered, and it doesn't count
  as a failure.

## Upgrading

```bash
uv tool install whyline@latest --force
```

Then restart `whyline console`, open **Agents**, choose **Jobs**, and run the
setup check.
