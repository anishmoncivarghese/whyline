# whyline 0.3.48

Take an idea from your phone to a reviewed plan and a running relay.

## What's changed

- **Create a spec and plan from Telegram.** After a brainstorm, choose the
  repository and its saved Set up (preselected by default). Auto drafts the
  spec and implementation plan, asks planner questions in Telegram, and sends
  both documents back as Word and PDF.
- **Start only after a final confirmation.** Start shows the repository,
  agents, and timeout one last time. After you confirm, whyline reruns its
  preflight and launches the relay only when those checks pass. Release tasks
  remain yours.
- **Control a run from its card.** Status reports the current task, stage,
  round, agent, elapsed time, and redacted recent log lines. A pause presents
  Resolve's relevant choices as buttons; Stop is one confirmed tap. Every tap
  is acknowledged immediately and followed by its result.
- **One-command Telegram setup.** `whyline idea telegram setup` configures the
  bot, chats, agents, assistant, document formats, repositories, and service.
  The same settings are available in the console's new **Inbox** screen under
  Agents mode.
- **Manage ideas in the console.** The new **Ideas** screen lists ideas and
  scores and can brainstorm, refine, drop, reopen, and export them. The console
  also detects a newer whyline release and can update itself with one click.
- **Honest diagnostics.** `whyline idea doctor` checks the Telegram token,
  allowed chats, service, webhooks, and macOS PDF conversion. Telegram errors
  appear in `whyline idea service status` instead of looking like silence, and
  `docs/idea-inbox.md` covers both new and existing bot owners.
- **Responsive, resilient background work.** Cards expose only actions that
  make sense for their state, name the agent that started, and give an expected
  duration. Whyline keeps the Mac awake during scoring and brainstorming,
  restarts jobs interrupted by sleep or shutdown, reports how long it was
  offline, and makes clear in the bot profile that replies require the Mac to
  be on.
- **Real PDF reports on macOS.** Brainstorms and plans use the native document
  conversion path, with a sample conversion included in `idea doctor`.

Needs whyline-relay 0.2.38.

## Upgrading

```bash
uv tool install whyline@0.3.48
```
