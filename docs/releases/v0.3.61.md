# whyline 0.3.61

A relay status line that tells you what is happening now: which task, which
stage, which agent, which round, how long this turn has taken, how many times
the task was sent back, and how far the tests have got.

## What's changed

- **A live relay status line.** Instead of `relay: JOB-24, claude… 5945s`,
  the console shows the task's place in the plan, the stage, the agent, the
  round and the time for this turn, for example
  `relay: JOB-24 (2 of 10, 10%) · implementing · claude · round 1 of 24 · 7m 02s`.
  After a rejection it reads `fixing after review 1`, then `re-review 2`. The %
  counts finished tasks in the plan; nothing guesses how far one task has got.
  Rerun counts appear once whyline-relay reports the stage; with the current
  relay they are just not shown.
- **Telegram status** includes the same live line for each repository with a
  running relay.
- **Copy part of the transcript.** **Copy** opens the transcript in a view
  where you can select just the lines you want and press **Copy selection**.
  **Copy all** still copies everything in one click.
- **Issues, numbered.** `whyline handoff --issue "<problem>"` (repeatable)
  records each problem separately and in priority order; `whyline sync`
  numbers them for the next agent. The project's tester prompt now asks for
  them.
- **Send-backs in the status line.** When a tester or reviewer sends a task
  back, the line adds `failed 2× (last: 2 issues)`, and an **Issues** button
  lists every round's outcome and issues for the current task.
- **Live test progress.** While tests or a review run, the line shows what
  the agent last reported, for example `suite 40%, 0 failed (codex says)`. It
  is labelled as the agent's own report.

## Upgrading

```bash
uv tool upgrade whyline
```

Then restart `whyline console`.
