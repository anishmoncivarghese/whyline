# whyline 0.3.47

Send an idea to your Telegram bot and get a brainstorm back.

## What's changed

- **Ideas from Telegram.** Send an idea to your bot and it replies with a
  card: **Brainstorm**, **Quick score**, or **Cancel**. Only private chats you
  allow are read (`whyline idea telegram allow <chat-id>`); messages from any
  other chat are recorded and ignored.
- **Brainstorm from your phone.** By default every available agent researches
  the idea in one pass. You can choose the models, passes, final writer,
  backup and timeout in the same message (`models: claude, codex` /
  `passes: 2` / `timeout: 30`). It runs in the inbox's own workspace, never in
  your repositories, and the synthesis comes back as Word and, where the Mac
  can make one, PDF.
- **A quick score is one tap away**, with the full report, Refine, Drop and the
  Excel workbook as buttons on the result.
- **Plain-language replies are read by an assistant** (`whyline idea
  assistant <agent> --backup <agent>`) that proposes a card. Nothing changes
  until you tap Confirm.
- **Runs without a terminal.** `whyline idea service on` runs the inbox from
  the existing scheduler while you are logged in. Replies retry until they are
  delivered, and a Mac that was off catches up on messages from up to about a
  day.

Needs whyline-relay 0.2.38.

## Upgrading

```bash
uv tool install whyline@latest
```
