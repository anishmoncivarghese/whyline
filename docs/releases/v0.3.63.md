# whyline 0.3.63

Ask questions about a running relay without disturbing it: a new **Chat** tab in Relay, and `whyline ask` on the command line. Needs whyline-relay 0.2.42, the same as 0.3.62.

## What's changed

### Relay chat
- **A Chat tab next to All files.** In Relay mode the Files pane now has four tabs: Working file, Plan, All files and Chat.
- **Ask about anything in the run.** Ask about the relay's status and progress, the process, the plan, or any doc or file in the repo. Each question goes to a fresh agent along with an up-to-date snapshot of the relay: the plan, the latest handoffs, recent decisions and the changed files.
- **Quick questions.** One click asks "What's it doing?", "Why did it stop?", "Plan progress" or "What's changed?". "Why did it stop?" appears only when the relay has stopped.
- **File links.** A `path:line` in an answer opens that file at that line in the Working file view. Paths outside the repo stay plain text.
- **History for each run.** Each repo and relay run keeps its own conversation under `~/.whyline/relay-chat/`. Clearing a conversation sets the file aside instead of deleting it.

### It never disturbs the relay
- **Read-only agents only.** The chat agent runs in its CLI's read-only mode, and an agent without one can't be chosen.
- **No interference with the relay's git.** Chat's git calls never take git's lock, so they can't block the relay's commits.
- **The relay itself is never touched.** Chat never stops, steers or resumes the relay, and never writes its state, plan or handoffs. A guard test enforces all of this.
- **Stop only stops your question.**
- **Quota.** Chat prefers an agent that isn't working on the relay. If none is free, the reviewer answers and the tab says it "shares quota with the relay".

### Settings and command line
- **Settings → Relay chat.** Choose the agent (Automatic or a read-only-capable one), the time limit in minutes, and the snapshot size. Only the fields you change are saved.
- **`whyline ask`.** It uses the same functions as the console, from the command line:
  - `whyline ask "why did it stop?"` asks a question.
  - `--history` shows the conversation.
  - `--clear` sets the conversation aside.
  - `--set-agent`, `--set-timeout` and `--set-snapshot-chars` change the settings.
- **Help and `docs/relay-chat.md`** cover the tab, the read-only guarantees, quota and history.

## Upgrading

```bash
uv tool upgrade whyline --upgrade-package whyline-relay
```

Then restart `whyline console`.
