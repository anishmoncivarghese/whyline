# whyline 0.3.40.1

The console no longer crashes while a brainstorm reports its progress.

## What's changed

- **The thinking line shows its text as written.** Brainstorm progress such
  as `[1/3] Codex starting pass-zero` was read as a Textual style tag, which
  raised `MarkupError` and closed the console. The line under the transcript
  now displays plain text, so brackets in any progress label are shown
  literally.

Needs whyline-relay 0.2.34; 0.2.34.1 or later fixes a Windows bug where
checking for a running relay sent Ctrl+C.

## Upgrading

```bash
uv tool upgrade whyline
```
