# whyline 0.3.6

Bare `whyline` now opens a small entry menu instead of immediately entering chat. You can start chat, choose a model before chatting, or open relay setup from the same command.

## What's new

- **Choose Chat or Relay.** The default remains chat; selecting relay delegates to `whyline-relay setup`.
- **Choose a model before chat.** The chat path can run `whyline model` first and then enter `whyline-relay chat`.
- **Keep the existing fallback.** If `whyline-relay` is not installed, bare `whyline` still prints its normal usage message.
- **No duplicated orchestration logic.** Whyline only delegates to the existing whyline-relay commands.
