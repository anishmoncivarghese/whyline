# whyline 0.3.8

The console foundation: `whyline console` gives an editable multiline
prompt for driving both Whyline and Whyline Relay from one session,
building on already-released, already-tested functions rather than
duplicating either package's own logic.

## What's new

- `whyline console` (requires `pip install 'whyline[console]'`) -- a
  keyboard-only REPL with a real multiline editor (selection, word
  deletion, history, paste).
- `/model`, `/route <chat|relay|command>`, `/status`, `/history`, `/help`,
  `/exit`.
- Whyline's own commands run in-process; Whyline Relay integration (when
  `whyline[relay]` is installed) calls its already-structured functions
  directly -- `chat.run_turn`, `preflight.run`, `running.live`/`state.load`
  -- rather than parsing subprocess text. `start`/`resume` call
  `whyline-relay`'s own CLI in-process, since their orchestration isn't
  factored into a reusable function.
- `whyline run`'s exec-and-hand-over design is untouched; the console
  never captures or supervises it.
