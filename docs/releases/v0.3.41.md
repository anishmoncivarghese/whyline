# whyline 0.3.41

Auto runs end to end: from a brainstorm to a generated plan to the relay,
started from the Plan form and driven from the main window.

## What's changed

- **Run stays off until Check passes.** The Auto form's Run button is
  enabled only by a clean Check fingerprinted against this exact form and
  this repository state. Any edit, a new file in the tree, or a stale
  fingerprint clears it, and Run says "This check is out of date. Check
  again." instead of starting.
- **A clean run starts the relay only after the generated plan passes full
  preflight.** Research, spec, and plan run first, failing over through the
  saved backup chain, and pause instead of inventing an answer to an open
  question. The relay is launched only when the generated plan passes the
  same preflight Set up runs.
- **A real failure pauses with the artifacts kept.** The research notes,
  spec, and draft plan stay on disk, and the run is checkpointed so Resume
  re-enters where it stopped.
- **Stop and Resume do not commit the same artifact twice.** Stop cancels
  the active agent; Resume continues from the checkpoint without re-committing
  what was already saved.
- **The three existing sources still end in Set up.** Brainstorm it, I'll
  describe it, and I have a plan already behave as before.
- **Set up chooses the relay timeout.** A Timeout row offers 30, 45, or 60
  minutes, or none. Check writes `timeout_minutes` only when it changed, and a
  saved value outside the list stays selectable.
- **Relay status while a run is live.** The saved pause from an earlier stop
  is shown as `Last pause`, not as the current state, and no longer offers
  Resume while an agent is running.
- Includes 0.3.40.2: the readable Agent/Backup/Model/Repo bar, the Automatic
  backup default in Set up and Plan, and failover on billing exhaustion.

Needs whyline-relay 0.2.36. This release does not turn on the Chat `none`
menu by itself.

## Upgrading

```bash
uv tool upgrade whyline
```
