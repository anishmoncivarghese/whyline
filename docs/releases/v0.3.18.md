# whyline 0.3.18

Five console improvements from using it for real: you can see when an
agent is working, who you're talking to and where, brainstorm with several
models at once, and move between repositories.

## What's new

- **Thinking indicator.** While a reply is pending, a line above the input
  shows `⠋ claude is thinking… 12s` (or "relay is working", or the current
  brainstorm step). It disappears when the reply lands or you press Stop.
  The keyboard console prints "claude is thinking..." before the reply.
- **Active agent and model in view.** The mode row's right side shows
  `claude · opus   │   repo: agentdock  ~/agentdock`, updated on every
  /model and /repo. The keyboard console's prompt shows it in chat mode:
  `(chat · claude · opus) >`.
- **Brainstorm button and `/brainstorm`.** A form asks for the topic, which
  models (ones you can't use are shown but disabled, with the reason),
  review passes and who writes the final synthesis. Each model researches
  independently, they review each other's drafts, and the chosen model
  writes it up to `docs/brainstorm/<topic>.md`. Progress appears in the
  transcript as it happens. Built on whyline-relay's own brainstorm engine.
  The keyboard console asks the same questions as prompts.
- **Repository shown on the right** of the mode row.
- **`/repo <path>` switches repositories**, after a confirmation that warns
  the transcript will be cleared and a fresh chat context started (each
  repository keeps its own chat history and model settings). `/repo` alone
  shows the current one. Paths may be relative or use `~`; anything that
  isn't inside a git repository is refused. If you were in Relay mode and
  the new repository has no relay setup, you're moved to Command mode.

## Known issue (in whyline-relay, not whyline)

whyline-relay's own `/brainstorm` (in `whyline relay chat`) offers
Antigravity under the key `agy`, which its chat then rejects. The console's
Brainstorm passes `antigravity` and isn't affected.

## How it was checked

- New tests: the thinking line appears and clears; the context label
  follows /model; the brainstorm form's validation, disabled models and
  hand-off to the runner; the runner's stage order, skipping of models
  relay can't use and final-model fallback; /repo validation, confirmation,
  cancel and switch (root, working directory and transcript); the keyboard
  console's prompts for both.
- Screenshots at 80x24 through 120x32 to check the form and dialogs fit and
  their text wraps.
