# whyline 0.3.60

Job search, part 4: import your CV as a PDF, pick it with the Mac file picker,
stop a CV review, accept or remove several companies at once, and read jobs
from Workday boards.

## What's changed

- **PDF CVs.** **Import CV…** and `whyline jobs profile import-cv <file>`
  accept `.pdf` as well as `.md`, `.txt` and `.docx`. A scanned PDF with no
  text, a password-protected PDF or a damaged file is refused with a plain
  message, and your existing CV is kept.
- **See what was read.** After any import, whyline shows how many characters
  it read and the first lines, so you can tell at once if a PDF came out
  jumbled.
- **Choose file….** The Import CV panel opens the Mac file picker, so no path
  needs typing or pasting.
- **A safer CV review.** **Review my CV** can be stopped. It refuses to run
  without a CV, saves pending preference changes first, and marks drafts that
  are older than your CV. Closing the Jobs screen asks before dropping unsaved
  preferences.
- **Several companies at once.** Tick rows in the Companies table to accept or
  remove them in one step, or accept every suggested company at once. The
  full reason for the highlighted company shows under the table. Suggested
  companies are still never fetched until you accept them.
  `whyline jobs companies accept|remove` take several names.
- **Workday job boards.** Companies whose jobs are on `*.myworkdayjobs.com`
  (most large banks and IT services firms) are now read like the other
  boards. whyline finds the Workday board from the company's careers page. If
  it can't, paste the Workday link with **Add company…** and the same name.
  whyline respects each Workday host's robots.txt and reads at most 40 new job
  descriptions per company per run.

New dependency: `pypdf`, used only to read PDF CVs.

## Upgrading

```bash
uv tool upgrade whyline
```

Then restart `whyline console`.
