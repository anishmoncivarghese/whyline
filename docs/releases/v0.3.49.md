# whyline 0.3.49

Send an idea to whyline by email and carry it through the same confirmed
workflow as Telegram.

## What's changed

- **Capture ideas by email.** Send a message with the subject `idea` (or no
  subject) from an allowed address. The message body becomes the idea, and
  optional `key: value` lines apply brainstorm settings.
- **Authenticate every sender.** Whyline accepts mail only from configured
  addresses whose authentication results show a DKIM or SPF pass. Duplicate
  messages are ignored using their Message-ID.
- **Confirm actions by reply.** Reply with the six-character code whyline
  sends to confirm each step. Codes are tied to the current idea revision, so
  stale or incorrect codes cannot start work.
- **Receive finished documents as attachments.** Word and PDF outputs are
  attached to the reply, and ideas captured by email also appear in Telegram
  when an allowed chat is configured.
- **Manage email access from the CLI or console.** Use `whyline idea email
  allow|deny|list`, or the Email section of the console's Inbox screen, to
  maintain the same allowed-sender list.

Needs whyline-relay 0.2.38.

## Upgrading

```bash
uv tool install whyline@0.3.49
```
