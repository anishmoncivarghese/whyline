# whyline 0.3.75

Release notes that are checked before you see them, a model picker for a running relay, and fixes from the last release day.

## What's changed

- **Release notes are checked, reviewed and checked again.** A fixed set of rules flags lines that are an agent talking instead of notes, such as "here are the release notes" or "let me know". A second agent then reviews the draft and can only remove or reword lines, never add one, and the rules run once more. The confirm window says who wrote the notes, who checked them and how many lines were removed, with a before and after. A problem in the check or the review never stops a release. (NOTE-1, NOTE-3, NOTE-4, NOTE-5)
- **A readable fallback.** When an agent's notes can't be used, you get a grouped commit list instead of the raw one, and a release with only housekeeping commits says `Maintenance release.` (NOTE-2)
- **Change an agent's model while the relay runs.** Each row in "Agents for this run" has a Model dropdown next to the agent. Save applies it from that agent's next turn, never the current one, and "Keep for future runs" also saves it to `config.toml`. A model belongs to the agent, so it changes on every role that agent plays. (LMD-1, LMD-2)
- **Releasing from a branch that is behind main works.** Ready now passes with `19 commits behind origin/main; Release brings them in first` and Start is enabled. If bringing main in would conflict, Ready says so and names the files before anything starts. (RDF-1)
- **A failed CI run names the jobs that actually stopped the release.** Jobs that also failed in the last run that passed are listed in one line and no longer blamed. (RDF-2)
- **A new agent is personal by default.** It is saved in `~/.whyline/agents/` and shows whichever repository is selected. A personal agent is only offered skills that are on this Mac for every repository. (RDF-4)
- **Antigravity keeps its allow list** when whyline runs it for an agent, an idea or release notes. whyline now needs whyline-relay 0.2.44 or newer. (RDF-5)
- **The console tells you when a newer whyline is installed.** The title shows `whyline <version> is installed · restart to use it` with the Restart button. Restarting leaves a running relay alone. (CRS-1)
- **A crash leaves a log.** The error is saved to `~/.whyline/crash.log` and the terminal says where. Help and `whyline doctor` show the last crash. (CRS-2)
- **The Ready check is more patient.** A slow reply from `gh` or git is tried once more before it counts as not ready. (CRS-3)
- **Scheduled assistant runs and access to the Mac.** You can check and grant access to Calendar, Reminders and Mail the way a scheduled run sees it. A refusal names the app that was refused, and you get an alert when a scheduled run never starts. (ASST-24, ASST-25, ASST-26)

## Upgrading

```bash
uv --no-cache tool upgrade whyline
```

If it stays on the old version, run it a second time.
