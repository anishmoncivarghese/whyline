# whyline 0.3.36

Agents mode: saved, read-only agents you run on demand.

## What's changed

- **Agents mode in the console.** The Agents tab lists your agents, shows
  one agent's details and recent runs, and runs it with **Run now**. **New**
  opens a form for the agent's name, instructions, main CLI and backups, with
  a plain-language **Review** before it's saved.
- **Repo and personal agents.** A repo agent is a TOML file committed with
  the repository; a personal agent lives under `~/.whyline/agents`. An agent
  whose file changes (for example through `git pull`) stops until you accept
  the new definition on this Mac.
- **Read-only by design.** An agent can read and search but never write.
  Each CLI runs with its verified read-only setting: Codex `-s read-only`,
  Claude `--permission-mode plan`, Grok with every permission grant removed,
  `--permission-mode dontAsk` and `--deny Edit/Write`. Antigravity has no
  read-only setting, so it can't run agents.
- **Main CLI and backups.** When the main CLI hits a usage limit, needs a
  login or isn't installed, the run moves to the next backup, and the run
  record says why. Other failures never switch CLI. An exit code of 0 alone
  never counts as success.
- **Run history and reports.** Each run keeps its final answer and log, and
  can write a report file. Runs are recorded in the whyline ledger.
- **`whyline agents`:** `list`, `show`, `run`, `history`, `pause`, `resume`,
  `accept` and `delete`, also available as `/agents …` in the console.

Scheduling (daily, weekdays, every N hours), folder-watch agents,
`whyline agents trigger` and notifications come in the next release.

Needs whyline-relay 0.2.32.

## Upgrading

```bash
uv tool upgrade whyline
```
