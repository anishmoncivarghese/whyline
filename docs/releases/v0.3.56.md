# whyline 0.3.56

Job search, part 1: start agents from templates, keep a private job profile,
let an agent review your CV, and build a checked list of companies to watch.

## What's changed

- **Agent templates.** `whyline agents templates` lists the built-in templates.
  `whyline agents new --from <template> [--name N] [--workdir DIR]` creates an
  agent from one. In the console, Agents → New agent first offers
  **Blank agent** or a template, prefilled and editable before saving. Template
  files are copied without overwriting, and never outside the agent's folder.
- **Jobs profile.** `whyline jobs profile` and the Jobs screen in Agents mode
  keep your CV and job preferences in `~/.whyline/jobs/`. It's a private folder
  (0700, files 0600), never in a repository, git or the ledger.
- **Review my CV.** `whyline jobs review` (or **Review my CV** in the console)
  runs an agent that drafts `profile.draft.md` and `rubric.draft.md`. You edit
  them and accept them with `whyline jobs review accept` or the console's
  Accept. A failed run writes nothing.
- **Companies to watch.** `whyline jobs companies list|suggest|add|accept|remove`
  and the Companies section of the Jobs screen. An agent suggests companies
  that fit your profile. Your own entries win over suggestions, and removed
  companies are not suggested again.
- **Job board check.** whyline itself works out which public job board each
  company uses (Greenhouse, Lever, Ashby, Workable, SmartRecruiters or
  Recruitee), using only those documented public endpoints. It sends a
  `whyline/<version>` User-Agent and uses a 15-second timeout. There is no
  LinkedIn, Indeed or Glassdoor scraping, and agents get no web access.

## Upgrading

```bash
uv tool install whyline@0.3.56 --force
```

Then restart `whyline console`, open **Agents**, and choose **Jobs**.
