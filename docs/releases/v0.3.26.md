# whyline 0.3.26

Requires whyline-relay 0.2.24, which stops brainstorms committing work that
isn't theirs.

## What's changed

- **Brainstorms (the console's Brainstorm button, `/brainstorm`, and
  `whyline relay chat`'s `/brainstorm`) commit only their own files**: the
  per-model notes, the shared `docs/brainstorm/<topic>.md` and the relay's
  tracking files. Before, every brainstorm turn committed everything in the
  working tree, so uncommitted work (whyline's own 0.3.19 changes, in fact)
  ended up in commits titled "brainstorm: … research". Other uncommitted
  changes now stay uncommitted, and so does anything an agent writes outside
  its brief.
- The one-time commit that saves a generated agent permission file no longer
  sweeps in unrelated work either.

The fix itself is in whyline-relay 0.2.24; this release makes it the minimum
version, so every whyline install gets it.

## Upgrading

```bash
uv tool upgrade whyline
```
