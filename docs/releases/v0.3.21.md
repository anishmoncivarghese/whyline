# whyline 0.3.21

Brainstorm roadmap item 1: decisions can be tied to the exact commit they
explain, and the committed record keeps exact times.

## What's changed

- **Exact time in `decisions.md`.** Each new entry gets a small hidden
  comment, `<!-- whyline-meta: {"v":1,"ts":"…"} -->`, holding the full
  timestamp. Previously only the day survived a clone, which capped
  `explain` at "medium" confidence on any fresh checkout. Entries written
  before this release are unchanged and still read at day precision.
- **`whyline note … --commit SHA`** binds a decision to the commit it
  explains (e.g. `--commit HEAD` right after committing). The sha is checked
  and stored in full. There is no automatic binding: without `--commit` a
  decision stays unbound, because a clean tree or the current HEAD doesn't
  prove which commit a decision is about.
- **`whyline attach DECISION_ID --commit SHA`** binds a decision recorded
  before its code landed. Any unique prefix of the id works. The binding is
  written to `decisions.md` as well as the local ledger, so it survives a
  clone; the latest binding wins.
- **`explain` uses bindings first.** A decision bound to the commit that
  wrote a line is "high" confidence with no timestamp guessing, and a
  decision bound to the whole commit (no files) counts too. A decision bound
  to a *different* commit is no longer attributed to this one by time
  window.
- `brief` and `sync` show `commit: abc1234` for bound decisions; `timeline`
  shows attachments.

## Compatibility

The new comment is separate from the existing `<!-- whyline-event: ID -->`
one, so older whyline versions still read every id correctly; they simply
ignore the exact time and binding.

## How it was checked

- 16 new tests in `tests/test_provenance.py`: format round trip, entries
  from before this release, malformed metadata, `note --commit` (short sha,
  `HEAD`, unknown), `attach` (prefix, latest wins, unknown, ambiguous, bad
  commit, surviving a clone), and `explain` from a clone with and without
  bindings.
- Two older tests that guarded the day-precision limit now target
  pre-0.3.21 entries, where that limit still applies; a new test confirms
  a current entry reaches "high" from a clone.
- The repository's own history loads unchanged (2,134 events, 207
  decisions), and this release's decisions are attached to its commit
  with `whyline attach`.
