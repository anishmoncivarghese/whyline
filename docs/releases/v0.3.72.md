# whyline 0.3.72

Release notes are drafted in an isolated read-only agent run. **Bring in main** accepts an Allow's allowlist and names dotfiles in full. Release messages show as plain text, so a `gh` timeout cannot crash the console. Finished plans move to `plans/done`.

## What's changed

- **Safe release notes.** whyline drafts release notes in an isolated read-only agent run.
- **Bring in main.** The step accepts an Allow's allowlist and names dotfiles in full.
- **Release messages.** Messages show as plain text, so a `gh` timeout cannot crash the console.
- **Finished plans.** Finished plans move to `plans/done`.

## Upgrading

```bash
uv tool upgrade whyline --upgrade-package whyline-relay
```

Then restart `whyline console`.
