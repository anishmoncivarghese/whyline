# whyline 0.3.7

Account capability gating is now available in the core Whyline CLI.

## What's new

- Detects configured Claude, Codex, Grok, and Antigravity capabilities.
- Supports persistent `whyline account enable` and `disable` overrides.
- Shows account availability and active overrides in account status output.
- Gates model selection and first-run entry-menu choices by available accounts.

## How it was checked

- 355 tests passed twice on the completed account-capability plan.
- The isolated scratch flow verified first-run detection and enable/disable model gating.
- Both planned tasks were approved by Codex.
