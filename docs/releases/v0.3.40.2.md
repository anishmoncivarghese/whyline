# whyline 0.3.40.2

The console's settings bar is readable again, the relay screens start with a
backup chain, and an agent that runs out of paid credit hands over to its
backup.

## What's changed

- **The Agent, Backup, Model and Repo bar shows its values.** The bar is one
  row tall, but its dropdowns, text boxes, "all repos" checkbox and Save button
  kept Textual's three-row bordered style and were clipped to their top
  border, so only the labels were visible. Each control is now a borderless
  one-row field with a shaded background, and Save stays on screen from 80
  columns up.
- **Set up and Plan open on the Automatic backup.** When no backup chain is
  saved, both screens now tick the Automatic order (your usable agents in
  preference order) instead of none. A chain you saved still loads as saved,
  and None still clears it.
- **Running out of credit fails over.** Needs whyline-relay 0.2.36, which
  treats `402 Payment Required` / "usage balance exhausted" and similar billing
  errors as a usage limit, so the relay switches the role to the next backup
  instead of pausing.

## Upgrading

```bash
uv tool upgrade whyline
```
