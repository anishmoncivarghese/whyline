# whyline 0.3.35.2

A readable agent dropdown.

## What's changed

- **The Agent dropdown in the context bar shows each agent on one line.**
  The open list is wider than the box, and agents whose login whyline can't
  check (Antigravity, Grok) read `login unchecked` there instead of wrapping
  "installed (login not checked)" over four lines. `/model` keeps the full
  wording.

Needs whyline-relay 0.2.32.

## Upgrading

```bash
uv tool upgrade whyline
```
