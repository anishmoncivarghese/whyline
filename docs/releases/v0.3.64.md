# whyline 0.3.64

Pause a relay safely and pick it up later without losing work, with safeguards for low battery, sleep and quitting. This release also improves the Chat tab, Check, the Issues view and Settings. Needs whyline-relay 0.2.42, the same as 0.3.63.

## What's changed

### Safe pause
- **Pause, Pausing… and Resume.** While a relay runs, Relay mode shows **Pause** next to Stop. Pause lets the current agent finish its turn and hand off, then stops. The status line shows **Pausing…** with the agent and the time so far, then **⏸ Paused by you**. **Resume** carries on with the next turn, and nothing is redone.
- **Pause now and Keep going.** **Pause now** cuts the current turn off after a one-line confirmation. The turn's changed files are recorded, and the agent is told to continue from them. **Keep going** withdraws a pause request.
- **Safeguards** in the new **Settings → Relay safety** section, or with `whyline relay-safety`:
  - a safe pause on low battery (15% by default)
  - what to do when the Mac wakes from sleep during a relay (ask, pause or off)
  - what quitting the console does during a relay (Pause safely and quit, Leave it running, or Cancel)
  - a hint to press Awake when a relay starts on battery
- **Help and `docs/safe-pause.md`** explain Pause, Pause now and Stop, and the safeguards.
- **A clearer release-task button.** While the relay waits on a release task, the Resume button reads **Mark released…** instead of a cut-off "Releas". It asks before marking the task done, and says that nothing is published by the button.
- **Send back first.** When a relay pauses because a reviewer's command was refused and the review was misread, Send back is offered first.

### Relay chat
- **A bigger question box.** It wraps and grows from 3 to 6 rows. Enter sends.
- **A working line.** While an answer is on its way, a spinner shows which agent is working and for how long. Stop shows "Stopping…".
- **Only the final answer**, with markdown styled and `path:line` links. Agents' working notes no longer appear.

### Check
- **Falls back to the backups.** When an agent is out of quota, not logged in, missing or fails, Check moves on to the next agent and says why.
- **Shows that it's working.** A busy line shows the agent and the seconds elapsed. Check is disabled while it runs, and a Stop button appears next to it.
- **A short report instead of a paragraph.** It has:
  - a health line (✓ Fine, ⚠ Quota risk, ⚠ Going round in circles, ✗ Stuck or ? Unclear)
  - a one-sentence headline and up to four findings with file links
  - suggested steps
  - buttons: **Apply when paused**, **Ask about this** (carries the report into Chat), **Check again** and **Close**
  The transcript gets one line that reopens the report.

### Issues, Settings and the top bar
- **A sent-back round never shows "0 issues".** When the handoff lists none, the issues come from the summary's bullets or the failing tests, marked "(from the summary/tests)", with a **Why:** line. The status line's count matches.
- **A roomier Settings screen**, with spaced, bold section headings in order and full-height dropdowns.
- **A model dropdown in the top bar.** It lists the selected agent's models, the default, and **Other…** for a custom id. A hint shows when the change isn't saved yet. Save accepts the agent's default, and a refused Save says why.

## Upgrading

```bash
uv tool upgrade whyline --upgrade-package whyline-relay
```

Then restart `whyline console`.
