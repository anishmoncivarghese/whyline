# whyline 0.3.13

Sub-project #6 of the unified console roadmap, "final cutover": bare
`whyline` now launches the richest console actually installed, instead of
always showing the plain Chat/Relay text menu -- and a real, pre-existing
bug in the mouse TUI's buttons and slash commands is fixed along with it.

## What's new

- Bare `whyline` (run inside a repo) now checks what's installed and
  launches the best available interface: the mouse TUI if `[ui]` is
  installed, else the keyboard console if `[console]` is installed, else
  today's exact plain-text Chat/Relay menu -- unchanged for anyone
  without either extra, or running outside a repo.
- Choosing relay mode with no `.whyline/relay/config.toml` yet hands off
  to `whyline-relay setup`, in both console flavors -- exactly the parity
  the old plain entry menu already had. The keyboard console execs
  inline, immediately; the mouse TUI defers the exec until Textual's
  `app.run()` has returned and the terminal is back to normal, since
  `exec` mid-render would leave the terminal broken.
- Fixed: the mouse TUI's Model/Route/History/Help buttons (shipped in
  0.3.11) previously called `dispatch()` directly with a slash command
  like `/model`, but `dispatch()` had no concept of slash commands at all
  -- clicking them, or typing a slash command into the TUI's own prompt
  bar, silently did the wrong thing (tried to run it as a literal chat
  message or subcommand instead of the intended action). Slash-command
  handling is now a single shared function both the keyboard console and
  the mouse TUI call, so both interfaces interpret `/help`, `/status`,
  `/handoff`, `/history`, `/route`, and `/model` identically.

## Non-goals (explicitly, for anyone comparing to the roadmap doc)

- The old plain-text entry menu is untouched and stays permanently as the
  zero-extras fallback -- not deprecated code, not scheduled for removal.
- No console-native relay setup wizard was built; the multi-turn
  Q&A (plan source, roles, backup chain) still lives entirely in
  `whyline-relay setup`, reached via handoff.
- Attachments (sub-project #7) remain deferred indefinitely.
