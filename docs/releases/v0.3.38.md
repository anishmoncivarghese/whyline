# whyline 0.3.38

Agent results can reach you after the run, and planning hands off cleanly.

## What's changed

- **Deliver agent results by email, Telegram, or a command.** Each personal
  agent can have one or more post-run destinations. Whyline keeps delivery
  credentials in its private per-Mac settings, records each outcome, and never
  lets a delivery failure change the agent run's result.
- **Useful documents, not raw blobs.** Markdown results can be rendered as HTML
  email and converted to DOCX while preserving headings, lists, links, code,
  blockquotes, and tables. If Word conversion is unavailable, the Markdown
  file remains the attachment.
- **Configure and recover deliveries from both interfaces.** The CLI and
  console can configure destinations, send tests, display delivery status, and
  resend a completed run. Telegram setup discovers chats without exposing the
  bot token in repository files.
- **Planning no longer leaves a phantom relay.** After spec or plan generation,
  the console releases the planner's live marker, commits shared decision
  history, and preselects the plan that was just created when Set up opens.
- **Console reliability fixes.** Personal Claude agents start correctly;
  scheduler state is clearer; Telegram dialogs tolerate closing during a
  check; Mail waits until it is ready; comma- and semicolon-separated email
  addresses work; and delivery state no longer appears as a broken agent.

Needs whyline-relay 0.2.32.1.

## Upgrading

```bash
uv tool upgrade whyline
```
