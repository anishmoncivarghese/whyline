# whyline 0.3.50

Keep Grok relay runs moving when a headless permission denial returns a
pretty-printed cancellation record.

## What's changed

- **Requires whyline-relay 0.2.39 or later.** That release recognises Grok's
  real `permission required:` log shape when the following JSON spans several
  lines, recovers the resumable session ID, and uses the relay's existing
  cancelled-turn retry path.
- **Prevents `uv sync` from restoring the affected relay.** Both Whyline's
  runtime and development dependency floors now require `whyline-relay
  >=0.2.39,<0.3`, and the lockfile resolves to 0.2.39.
- **No Whyline application behavior changed.** The parser fix lives in
  whyline-relay; this patch aligns Whyline's packaging with that fixed release.

## Upgrading

```bash
uv tool install whyline@0.3.50 --force
```

Restart any open Whyline console after upgrading so it imports the new relay
package, then resume the paused run from Relay mode.
