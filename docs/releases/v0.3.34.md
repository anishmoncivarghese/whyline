# whyline 0.3.34

From an idea to a running relay in one guided flow: brainstorm, review the
synthesis, write a spec, plan from it, choose roles, and release tasks that
wait for you.

## What's changed

- **`start` (or `run`) asks first:** use a saved plan, or create one.
- **Creating a plan starts with a brainstorm** by default ("Brainstorm it");
  "I'll describe it" and "I have a plan already" stay as quick paths. Pick the
  Drafter and Reviewer once, in the same form.
- **Synthesis review:** the brainstorm's Final Synthesis appears in the main
  window -- approve it, say what to change, or answer its open questions.
- **Specs:** an approved synthesis (or a description, with "Write a spec
  first" ticked) becomes a design spec, drafted and reviewed by agents and
  approved by you, saved to `docs/specs/<name>.md`. The plan is then written
  from it.
- **Roles:** Set up shows **Committer: whyline (automatic)** -- the relay
  commits approved work itself -- and a **Release** role, "you" by default.
- **Release tasks wait for you:** the relay pauses with the task's steps as
  a checklist; do them, then type `done` (or `skip`).

Needs whyline-relay 0.2.31.

## Upgrading

```bash
uv tool upgrade whyline
```
