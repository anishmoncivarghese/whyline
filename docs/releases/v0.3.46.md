# whyline 0.3.46

An inbox for ideas, and a Resolve that gets you unstuck instead of in a loop.

## What's changed

- **`whyline idea` keeps every idea.** Ideas live in a local database under
  `~/.whyline/ideas/` and in `~/.whyline/ideas/ideas.xlsx`, which is rebuilt
  from that database after every change. `add`, `list`, `show`, `refine`,
  `drop`, `reopen` and `export` manage them; `doctor` checks the folder, the
  database, the workbook and which agents can run unattended.
- **A quick score.** `whyline idea score` runs one read-only agent turn that
  lists the sources it actually checked, rates usefulness and complexity 1-9,
  and gives a YES / NO / NOT YET verdict. `whyline idea agents` sets the
  fallback order.
- **Reports as Word and PDF.** Reports come as Word and, where the Mac can make
  one, PDF. `whyline idea documents` picks Word, PDF or both.
- **Resolve offers another agent.** When an agent times out, Resolve offers
  "Use <agent> instead" beside a longer timeout. When an agent's quota runs out
  and the relay could not switch by itself, Resolve offers the other logged-in
  agents, backup chain first.
- **Ask agent shows that it is working** and reads the agent's answer
  correctly; it no longer reports an empty recommendation.
- **Files opens the newest changed file** when you turn it on mid-run, instead
  of waiting for the agent's next write.
- **Set up's Check no longer loops on its own file.** Saving the Resolve choice
  no longer leaves the working tree dirty.

Needs whyline-relay 0.2.38.

## Upgrading

```bash
uv tool install whyline@latest
```
