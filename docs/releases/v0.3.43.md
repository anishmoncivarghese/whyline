# whyline 0.3.43

See the file an agent is writing, live, next to the console.

## What's changed

- **Files splits the console and follows the file being written.** A Files
  button in Chat, Relay, and Agents opens a read-only pane beside the
  console. While a turn or a relay run is busy, the pane shows the file the
  agent wrote most recently and jumps to the first line that differs from
  the last commit. The pane starts hidden; turning it off keeps what it
  showed.
- **Only real writes count.** Files that were already dirty when the run
  started stay off the pane until they change, and a file the agent only
  read never appears. Binary, very large, and non-UTF-8 files show a short
  notice instead of their bytes.
- **Earlier and Later step through this run's files.** Holding an earlier
  file keeps it on screen; newer writes only update the path line until you
  step forward. Saving the same file again keeps your scroll position and
  says it was updated.
- **A relay task in another repository is followed there too.** Its files
  are shown as `repo-name:path`.
- **Narrow windows stack the split.** Below 120 columns the file pane sits
  above the console, so the prompt and every button stay reachable at 80×24.
- **Set up and Plan explain a missing agent instead of crashing.** With no
  agent CLI installed, they say which agents to install and show the
  doctor's agent lines, instead of raising an error.
- **Windows fixes.** Closing the console during an Auto run no longer fails
  when the console and the run release the same file at once.

Needs whyline-relay 0.2.36.

## Upgrading

```bash
uv tool upgrade whyline
```
