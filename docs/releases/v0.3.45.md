# whyline 0.3.45

Test plans that stay paired with the work, and safer recovery when a run stops.

## What's changed

- **Plan, Brainstorm, and Auto can add a Test planner.** The optional planner
  writes a test plan beside the implementation plan, and the Reviewer reviews
  both together.
- **Every phase ends with a Verify task.** Its scenarios automate the checks
  for that phase, so the evidence travels with the plan instead of living in a
  separate checklist.
- **Manual checks gate a release.** The relay waits for each required manual
  check, and you pass or fail it from the console with a note recording what
  happened.
- **Failed Resume launches Resolve automatically.** Recognised recovery
  failures open the guided recovery flow without an extra click.
- **Resolve points to the agent's own login.** When Claude, Codex, or Grok has
  logged out, Resolve offers that agent's login action. A login always waits
  for your click and is never started automatically.
- **Sticky failover is quota-aware.** Resolve no longer recommends resetting a
  role to an agent that may still be out of quota.

Needs whyline-relay 0.2.38.

## Upgrading

```bash
uv tool install whyline@latest
```
