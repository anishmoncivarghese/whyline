# whyline 0.3.52

Choose which AI subscriptions Whyline may use, from one Settings screen in the
console.

## What's changed

- **Settings for AI subscriptions.** A Settings button now sits in the shared
  console controls in Chat, Relay, and Agents. Tick the Claude, Codex, Grok,
  or Antigravity subscriptions Whyline may use. Check selected tests only the
  ticked ones, Save writes all four choices at once, and Cancel changes
  nothing.
- **Disabled providers stay out of the way.** A provider that is off is not
  offered in Chat, backup, Brainstorm, Relay Set up, saved Agents, or Idea
  Inbox choices, and Whyline never launches its CLI to check it.
- **No silent fallback.** When nothing is enabled, Chat, Brainstorm, and
  Relay Set up say so and offer Open Settings. Whyline no longer quietly falls
  back to Claude.
- **Saved Agents and the Idea Inbox respect Settings.** A saved Agent whose
  CLI is off stays listed and inspectable. Its run uses an enabled backup
  under the existing backup rules, or stops before any provider starts and
  tells you what to enable.
- **Relay Set up opens at once.** Model lists are read from cache first, and
  Antigravity's model list is fetched in the background with a "Checking
  models…" note. A failed fetch leaves manual entry usable.
- **Honest login labels.** Grok and Antigravity show "installed (login not
  checked)", because their CLIs have no plan check. Claude and Codex keep
  their detected plan labels.
- **Scripts.** `whyline account status|enable|disable|detect` use the same
  machine-wide choice. `detect` checks enabled providers only.

## Upgrading

```bash
uv tool install whyline@0.3.52 --force
```

Open `whyline console` and press **Settings** to choose your subscriptions.
An existing install keeps every provider it already detected as enabled.
