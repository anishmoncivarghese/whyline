# whyline 0.3.40

Plan gains an Auto source that collects everything a brainstorm-to-release
run needs, and checks it without touching your repository.

## What's changed

- **Auto, a fourth Plan source.** Next to Brainstorm it, I'll describe it, and
  I have a plan already, Auto (brainstorm to implementation) gathers the
  whole run in one form: the research agents, review passes, final
  write-up, per-agent timeout, and attachments; who drafts and reviews the
  plan; the implementer, tester, reviewer, and release; and the shared backup
  chain. A one-line summary reads it back, for example
  `Claude + Codex research → Claude synthesizes → Grok drafts, Codex reviews →
  Grok implements, Claude tests, Codex reviews → whyline commits → you
  release. Backup: Claude.`
- **Check writes nothing under the repository.** Check runs the repository
  checks, agent logins, inputs, planning, execution, concurrency, and what a
  run would write, and prints them under those headings with a `fix:` hint on
  anything that is not ok. It does not save roles, prepare agents, select a
  plan, or commit.
- **Antigravity trust is settled first.** When the form names Antigravity and
  this repository has not decided yet, Check asks Trust it or Not now before
  it runs. Escape cancels without writing anything.
- **A passing Check cannot start work yet.** A clean Check is fingerprinted
  against the exact form, attachments, models, logins, and repository state;
  any change clears it. There is no Run button in this release; the runner
  arrives in a later one.
- **`done` and `skip` work after a console restart.** At a release pause the
  console now reads the release task back from the relay's saved state, so
  typing `done` or `skip` (or switching into Relay mode) works even after you
  reopen the console. With no release pause they say so instead of reporting
  an unknown command. The keyboard-only console has the same two commands.

Needs whyline-relay 0.2.34; 0.2.34.1 or later fixes a Windows bug where checking for a running relay sent Ctrl+C.

## Upgrading

```bash
uv tool upgrade whyline
```
