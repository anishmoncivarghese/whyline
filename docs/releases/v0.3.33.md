# whyline 0.3.33

Attach screenshots and files in Chat, Brainstorm and Plan.

## What's changed

- **Attach** next to Send: choose files in Finder, or **Paste screenshot**
  (or type `/paste`) after copying a screenshot to the clipboard
  (Cmd+Ctrl+Shift+4). Dropping files onto the prompt asks
  "Attach these files?" -- ordinary pasted text is never treated as files.
- Attachments show above the prompt with their size and whether the chosen
  agent can see them. All four agents read images by path; codex also gets
  images directly. If an agent may not be able to open something, you're
  asked once before sending.
- The Brainstorm and Plan forms have the same Attachments row (in Plan it
  replaces "Reference documents"); every agent in the brainstorm, and the
  plan's drafter and reviewer, get the same files.
- Copies live in git-ignored `.whyline/attachments/` and are deleted after
  7 days. Limits: 25 MB per file, 50 MB and 10 files per message.

Needs whyline-relay 0.2.30.

## Upgrading

```bash
uv tool upgrade whyline
```
