# whyline 0.3.25

Brainstorm roadmap item 6, the last: Antigravity sessions are recorded like
Claude Code and Codex sessions, and `whyline doctor` checks everything in one
place.

## What's new

- **Antigravity hook.** `whyline init` now adds a `whyline` entry to
  `<repo>/.agents/hooks.json` when `agy` is installed (or `.agents/`
  exists), keeping any other hooks in that file. It records:
  - a session start at the first model call of a conversation,
  - each file an agy file-writing tool changes (`TargetFile` inside the
    repo; reads and failed calls are ignored),
  - a session end, with agy's termination reason.
  This is built on payloads captured from a real agy 1.2 run, not only the
  documented contract (the tool call on `PostToolUse` is undocumented but
  present). `PreToolUse` is deliberately not used: its reply must carry a
  permission decision, so a recording hook would change what the agent may
  do. Antigravity only loads workspace hooks in folders you have trusted;
  whyline never edits that setting.
- **`status`** shows the Antigravity hook when Antigravity is in use.
- **`whyline doctor`** runs every health check with its fix: set up;
  AGENTS.md block current; each agent's hook configured and actually
  recording; Antigravity trust for this folder (read-only); stale claims,
  overlapping live claims, a finished handoff never closed; ledger
  readability and size; prompt text left over from before the capture
  policy; decisions.md merge conflicts; relay installed. `--json`; exits 1
  only on a failure.

## How it was checked

- 19 new tests in `tests/test_antigravity_and_doctor.py`: installing and
  merging the hook, refusing an unreadable file, each agy event (including
  reads, failures and paths outside the repo being ignored), always
  answering `{}`, init with and without agy, status, and every doctor check
  in its good and bad states.
- One real agy run in this repository with a probe hook, to capture the
  payloads the hook handles.
- `whyline doctor` on this repository reports, correctly: an outdated
  AGENTS.md block, no Antigravity hook yet, 24 stale claims, the FC-3
  handoff never closed, and 1.49 MB of prompt text from before 0.3.23.
