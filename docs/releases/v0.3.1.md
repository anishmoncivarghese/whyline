# whyline 0.3.1

`whyline run` now supports Antigravity (`agy`) alongside Claude Code and Codex, and the README's Gemini note is corrected — Gemini CLI itself is dead, not merely unsupported.

## What's new

- **`whyline run antigravity "<task>"`** hands the terminal to Antigravity, the same way `run claude`/`run codex` already do. `agy` needs `-i`/`--prompt-interactive` to seed a session with a prompt and then continue interactively — the same shape a bare `claude "<prompt>"`/`codex "<prompt>"` already gets for free — confirmed against `agy --help` and a real invocation, not guessed.
- **`whyline run`'s accepted agent names now come from one place.** `cli.py`'s argparse `choices` previously hardcoded its own `("claude", "codex")` tuple, separately from `runner.AGENTS` — the two had already drifted (neither ever listed a third agent). `choices` is now `tuple(runner.AGENTS)`, so they cannot drift apart again.

## Things to know

- **Gemini CLI is dead, not "not supported."** Its free personal tier was withdrawn; Antigravity is Google's real, working successor and is not the same binary or invocation. The README's Honest Limitations section is corrected to say so.
- Antigravity was already documented as a `generic`-adapter recipe for [whyline-relay](https://github.com/anishmoncivarghese/whyline-relay) (0.2.x). This release is whyline's own `run` command gaining the same agent directly, independently of the relay.

## Upgrading

`uv tool upgrade whyline`. Nothing else to do.

## How it was checked

- 263 tests (252 before).
- `agy -i "<prompt>"` was verified for real: run with piped `/dev/null` stdin (so it cannot actually engage), it failed only with "could not open TTY" — proof the flag itself parses correctly and the CLI proceeds to launch its interactive session, the same failure a real terminal-less sandbox would produce for `claude`/`codex` too.
- `whyline run --help`, run against the local editable source (not the previously-installed 0.3.0), was checked directly to confirm `{claude,codex,antigravity}` is what argparse actually offers, not just what the source claims to offer.

## Known issues

Same as 0.3.0. The `relay` extra still pins `whyline-relay<0.3`; whyline-relay is at 0.2.12, so this remains unaffected for now.
