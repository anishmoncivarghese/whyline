# whyline 0.3.55

The morning brief can read Reminders when Terminal (or your terminal app) is
allowed, and the Assistant screen shows which permissions are granted.

## What's changed

- **Reminders read through EventKit.** Reading reminders needs
  Privacy & Security > Reminders, not only the Automation switch. The old
  AppleScript read never showed that prompt, so a refusal looked like an
  Automation error even with the switch on. Reminders now works like
  Calendar: macOS asks properly, and a refusal points at, and
  **Open System Settings** opens, the Reminders page.
  `whyline idea brief open-settings reminders` opens it from the CLI.
- **Access line.** Under "Morning brief" the Assistant screen shows
  `Access: Calendar … Reminders … Mail …` (granted, denied or not asked yet),
  updated after each Grant button. Mail shows the last Grant's result, since
  macOS answers for Mail only by asking. CLI: `whyline idea brief access`.
- **Mail and Reminders tried separately.** A refusal for one no longer hides
  the other's result.
- **Docs.** `docs/assistant.md` lists the Reminders page.

## Upgrading

```bash
uv tool install whyline@0.3.55 --force
```

Then restart `whyline console`. If the Access line says Reminders denied, open
System Settings > Privacy & Security > Reminders and turn on your terminal app.
