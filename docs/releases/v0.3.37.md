# whyline 0.3.37

Agents that run on their own: on a schedule, when files appear in a folder,
or when something calls `whyline agents trigger`.

## What's changed

- **Scheduling.** An agent can run daily at a time, on weekdays, or every N
  hours. Turn the scheduler on from the Agents tab (**Scheduler**) or with
  `whyline agents scheduler on`. It is one LaunchAgent that checks for due
  agents every 2 minutes and at login; `scheduler off` stops it and
  `scheduler status` says whether it's loaded and when it last ran.
- **Catch-up after sleep.** A Mac that was asleep or off runs each missed
  agent at most once when it wakes, and records the older due times as
  `missed`. A sleeping MacBook is not woken to run an agent.
- **Each due run happens once,** even when two checks fire at the same moment.
- **Folder-watch agents** run when files appear in a folder. Thirty files in
  a minute start one run, not thirty.
- **`whyline agents trigger <name> [--file PATH ...]`** runs an agent as an
  event, for Mail rules, Shortcuts and hooks. It refuses (exit code 3) when
  called again before the agent's minimum gap.
- **The Mail recipe.** `whyline agents mail-script <name>` installs a script
  for a Mail rule that hands the message to an agent; see
  `docs/agents-mail-recipe.md` in the repository.
- **Backups while a CLI waits out a usage limit,** and the next runs skip it
  until its reset.
- **After a run:** an expired login pauses the agent, three failures in a row
  mark it as needing attention, failures back off before the next try, and
  you get a notification.
- **An empty `whyline agents list`** now says how to create your first agent.

Scheduling needs macOS for now; on other systems agents still run with
**Run now** and `whyline agents run`.

Needs whyline-relay 0.2.32.

## Upgrading

```bash
uv tool upgrade whyline
```
