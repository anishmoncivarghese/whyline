# whyline 0.3.10

Console relay lifecycle views (sub-project #3 of the unified console
roadmap): a relay pause now renders as structured fields instead of raw
captured text, and `/handoff` shows the current handoff record.

## What's new

- A relay pause in `whyline console`'s relay mode shows a labeled failure
  kind (`rate-limit`, `auth`, `no-handoff`, `round-cap`, `blocked`, or
  `other`) plus the task, reason, log path, and resume command as clean
  structured fields -- built from whyline-relay's own already-structured
  state, not parsed from raw subprocess text.
- New `/handoff` command shows the current handoff record (from/to/status/
  summary/questions), reusing whyline-relay's own `handoff.read` unchanged.
