# whyline 0.3.51

Inspect the files that matter during a Relay run without leaving the Whyline
console.

## What's changed

- **Three Relay file views.** The Files pane now offers Working file, Plan,
  and All files so you can move between the agent's current output, the active
  plan, and the repository without opening another application.
- **Live, read-only plan view.** Whyline follows the active Relay plan, reloads
  it when it changes, preserves your scroll position during updates, and keeps
  working-file updates from replacing what you are reading.
- **Repository browser.** All files presents an expandable tree, hides `.git`
  and paths that escape the repository, opens text files in the console, and
  reports binary or deleted files safely.
- **Persistent navigation.** Returning to All files restores the same expanded
  tree, while returning to Working file shows the newest agent output.
- **Safer error display.** File and permission errors are rendered as literal
  text, so strings such as `[Errno 13]` cannot be interpreted as console markup.

## Upgrading

```bash
uv tool install whyline@0.3.51 --force
```

Open `whyline console`, choose Relay, and press **Files** to use the new views.
