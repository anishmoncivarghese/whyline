# whyline 0.3.71

**Release** can start from a relay branch: it brings in main first, with conflict cleanup, and shows how the branch diverges and which plans are finished. After the push it updates a clean main checkout. Set up keeps each target's last check, and an unreleased current version is selected by default. The console no longer crashes on links.

## What's changed

- **Bring in main.** From a relay branch, Release runs a safe **Bring in main** step with conflict cleanup, and handles finished plans. The console and the CLI show the release source: branch divergence and finished-plan reporting. The **Bring in main** setting is persisted.
- **The other main checkout.** After the push, whyline updates the other clean main checkout and preserves a dirty checkout.
- **Set up readiness.** Release → Set up persists and refreshes per-target readiness rows, and collapses blank rows.
- **Unreleased current version first.** whyline detects when the current version has not been released yet and selects it by default across the release.
- **Fixtures and fake test secrets.** The security scan skips dependency fixtures. A secret in a test includes Allow guidance.
- **Release docs.** The docs cover bringing in main after a relay, conflicts, and plans.
- **Links in the console.** `rich` is pinned below 14.2 so the console stops crashing on links.

## Upgrading

```bash
uv tool upgrade whyline --upgrade-package whyline-relay
```

Then restart `whyline console`.
