# whyline 0.3.62

Change agents while a relay runs, carry on after a usage limit with one click, let Resolve fix a stuck relay for you (with approval and undo), and set how many rounds a task gets. This release needs whyline-relay 0.2.42.

## What's changed

### Change agents while a relay runs
- **Agents for this run.** Open it from a running relay to see which agent holds each role, and switch one. The change takes effect from that role's next turn. The relay is never interrupted.
- **Pending changes in the status line.** The status line shows a pending switch until the relay picks it up.

### Carry on after a usage limit
- **Set up labels agents that can't run** (not installed, turned off in Settings, or out of usage), with the reason, and warns before you pick one.
- **Continue with <agent>.** When a relay pauses on a usage limit, this button continues with an agent that is ready, in one click.
- **Resolve recommends a ready agent** for limit pauses.
- **Set up from a pause** keeps the paused task's own unfinished changes instead of refusing because the tree is dirty.

### Resolve can fix things, safely
- **A conversation in Resolve.** Ask the agent about the pause, and the conversation is kept for that pause.
- **Fix with approval.**
  - The agent can propose and make a fix. It can edit files but cannot commit.
  - You approve the commands it runs and the catalog actions it takes.
  - Whyline takes a snapshot first, so **Undo fix** puts everything back.
- **Check, then continue.** Before resuming, whyline runs the doctor and the task's tests, and resumes only when they pass.
- **Check a running relay.** A read-only health check of a relay that is still running, which can propose a pause.
- **Auto guard rails.**
  - Auto mode tries one recovery per pause. It recognises a pause by the task, round, stage and reason, not just the round number.
  - It uses only safe steps and records every attempt.
  - When it has already tried, it says so instead of repeating itself.

### Rounds and status
- **Round cap in Set up.** The default is 24, with a warning when the cap is set low. `whyline relay rounds [N]` shows or sets it from the command line.
- **Add rounds.** A round-cap pause offers **Add 6 rounds and resume**, or **Set round cap…** to pick a number. Typing `rounds N` in the relay input does the same.
- **The status line shows "N of T, X%" while a task runs**, not only after a pause.

### Smaller fixes
- **Only real model ids** appear in model lists. A model is checked before it is saved, so a bad id like `claude-opus-5-5-high` can no longer stop a relay.
- **Ask agent** has a time limit (relay-derived, at most ten minutes), shows that it is working, and can be stopped.
- **Resolve says when a pause cause repeats,** and marks rejections that a later round has already answered.
- **Test command in the console.** Set up shows the test command the relay uses (marked "(detected)" when you haven't set one) and lets you change it.
- **Brainstorms move to a separate worktree while a relay runs.** That way they never touch the relay's checkout. The console and `whyline doctor` list these worktrees and can remove them safely.
- **Antigravity's setup warning** now matches whyline-relay 0.2.42: agy 1.4.12 or later is needed.
- **Fix mode's guard catches a symlink that points to itself** on Python 3.13, which no longer reports the loop on its own.
- **Fixed flaky console tests** around the relay setup screen.

## Upgrading

```bash
uv tool upgrade whyline --upgrade-package whyline-relay
```

Then restart `whyline console`.
