# whyline 0.3.35.1

Stop stops the relay.

## What's changed

- **Stop interrupts the relay now**, as Ctrl+C would: the agent's current
  turn ends and the run pauses. Resume carries on from there. Before, Stop
  only asked the relay to pause after the agent finished its turn, which
  could take many minutes. "Stop it, then quit" does the same. `/relay stop`
  still pauses after the current turn, if you'd rather wait.
- **Stop works for a relay this console didn't start.** A relay keeps running
  after the console that started it closes; a new console now sees it within
  a second and can stop it, instead of showing Stop greyed out.

On Windows, Stop still pauses after the current turn: a console can't send
Ctrl+C to another process there.

Needs whyline-relay 0.2.32.

## Upgrading

```bash
uv tool upgrade whyline
```
