# whyline 0.3.37.1

A Codex agent's answer is its reply.

## What's changed

- **Fix:** an agent run by Codex saved Codex's whole session (banner,
  settings, your instructions, then the reply) as its answer, so history, the
  Runs view and the notification showed the transcript. The answer is now
  Codex's last message only. Claude and Grok agents were not affected.

Found by the live scheduler check after 0.3.37: a daily agent ran on time
through the scheduler, read-only, exactly once.

Needs whyline-relay 0.2.32.

## Upgrading

```bash
uv tool upgrade whyline
```
