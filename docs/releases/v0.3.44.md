# whyline 0.3.44

Per-attempt timeouts you choose, and a Stop that really stops.

## What's changed

- **Chat has a timeout on the bar.** Pick 5, 15, 30, 45, or 60 minutes, or
  none. The value is captured when you press Send, so changing it mid-turn
  does not touch the running attempt, and choosing it does not need Save.
- **`/timeout` reads and sets it.** `/timeout` shows the current limit,
  `/timeout 30` or `/timeout none` changes it, in any mode.
- **Stop cancels the attempt in flight.** In Chat and in Brainstorm, Stop
  ends the running agent instead of waiting for it, and a late result from
  the cancelled attempt is discarded instead of being shown.
- **Brainstorm and plan synthesis accept none.** A long brainstorm can run
  without a per-attempt limit.
- **Relay Set up writes `timeout_minutes`, including none,** and leaves it
  alone when you did not change it.
- **Scheduled Agents keep 1 to 240 minutes.** None is not offered for
  unattended runs.
- **`/help` explains the per-attempt limit,** including provider limits
  that apply regardless of this setting.
- **Set up no longer crashes on check text with square brackets.** A relay
  hint such as `[agents.antigravity]` was read as styling and closed the
  console; check results and form errors now show as plain text.

Needs whyline-relay 0.2.36.

## Upgrading

```bash
uv tool install whyline@latest
```
